# One-Liner Laugh Lab — The Robot Vacuum's Sock Excuse

Entry for make.fun's **One-Liner Laugh Lab** bounty (`u-suroso-69-one-liner-laugh-lab-6ccf3aae`): a program that writes exactly one funny line — the excuse a robot vacuum gives after eating a sock.

The winning line (chosen from 3 candidates scored against the judging rubric in [CANDIDATES.md](CANDIDATES.md)):

> I thought it was a dumpling. In my defense, it was stuffed with foot.

## Run it

```sh
node main.ts
```

`main.ts` (Node 22, deterministic, no network) writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
